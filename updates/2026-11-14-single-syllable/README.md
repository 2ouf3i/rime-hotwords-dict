# Ninan single-syllable calibration, 2026-11-14

Chinese 59b1df3f changes no word forms, readings or inputs. The builder (scripts/build-pinyin-dict-20261114.mjs) adds a final, lower-only calibration step computed from the same inputs on every build. Devices import the bundled base table before this main table; for a single character with the same reading only the first table's weight is used, while multi-character words take the larger weight. The two tables differ in scale by about a hundred times, so two-syllable words whose spelling is one syllable, and characters whose reading exists only in this table, outranked common characters. The step lowers 288 character readings absent from the base table (mapped to the base scale using medians of characters present in both, only where their place among base characters changes) and 78 two-character words spelled as one syllable (placed where the upstream scale ranks them among that syllable's characters, never below 1/30 of their weight). The full list is the per-build report expected-single-syllable-calibration.tsv. Fixed rime-ice da1fbe602e38f26db846fa10120ee64c2b0324c0 and all prior attribution remain.
