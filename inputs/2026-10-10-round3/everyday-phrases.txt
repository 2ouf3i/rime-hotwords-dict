# Ninan 日常短语表 —— 上游词库里**没有**的日常短语,每次构建拼音词库时加进主表
# (backend/scripts/build-pinyin-dict.mjs 的 --phrase-weights,可以给多次;这一份排在手写的 phrase-weights.txt 后面)。
#
# 写法(与 phrase-weights.txt 相同,这一份每行都带拼音):词<Tab>权重<Tab>拼音(小写,音节之间一个空格)
#
# 为什么要有这张表(2026-10-07):简拼评测的留出集里有 17% 的日常短语词库里根本没有(我在上班、我晚点到、下周再说 …)。
# 没有整词时,纯首字母几乎从不出想要的那句(2.1%);连全拼都常拼错(wowandiandao 出「我玩颠倒」、haodeshoudaole 出「好的受到了」)。
# 改权重救不了,只能补词。手写的权重表(phrase-weights.txt)只管「已有的词排第几」,新词放在这一份。
#
# ── 一、从 Tatoeba 的中文例句里数出来的(157 条)──
# 来源与许可:Tatoeba(https://tatoeba.org)的中文例句导出,CC BY 2.0 FR。我们用的是从例句里数出来的
# 「哪些短语单独成句、各出现在多少个句子里」和短语本身(日常用语),不收任何完整的例句。
# 怎么来的:backend/scripts/mine-everyday-phrases.mjs(下载地址、校验和、数法都在它头部)数出
# 「在 2 个以上的句子里单独成句、2 ~ 5 个字、词库里没有」的短语 401 条 —— 「单独成句」= 在别人写的句子里前后都是句读,
# 不是从长句中间截出来的半截。然后人过了一遍(2026-10-07),留下 157 条。去掉的是:
#   - 教科书式的陈述、带具体的人 / 国名 / 物件的(我是英国人、他不是诗人、我有两只猫);引文、谚语、宗教文本(太初有道、下雨天留客);
#   - 从句开头或引语开头、后面必然还有话的(因为他病了、他对我说、天气预报说);不雅或沉重的(他自杀了);
#   - 繁体转简体转坏了的(不是幺);
#   - **加了会抢掉同音说法的**:把每条短语的全拼喂给引擎,现在出来的首选如果是另一句同样说得通的话,就不加
#     (不坐了 / 不做了、他会来吗 / 他回来吗、你说的对 / 你说得对、你喜欢哪个 / 你喜欢那个);带「她」的一律不加
#     (加了「她生病了」而没有「他生病了」,tashengbingle 就先出「她」)。留下的这些,要么引擎现在的首选就是它,
#     要么现在的首选是拼错的(我恐高 / 我控告、我不饿 / 我不哦、你早点睡 / 你早点水)。
#
# ── 二、上一轮简拼评测量到「词库里没有」的那些(45 条)──
# scripts/rime-abbr-cases.tsv 的 held 组(2026-10-07 中午写的日常短语,自己按常识写的)里,上游词库没有的那 47 条,
# 去掉与上面重复的、后面必然还有话的(我今天去、我明天去)。这是「已知缺的先补上」,**不代表同一类短语都补了** ——
# 这一类(人称 + 在 / 晚点 / 一会 + …、好的 + …、… + 一下)Tatoeba 里几乎没有(47 条里只找得到 3 条),
# 要系统地补得另找聊天语体的来源;补之前新写的那批留出样本(held2)量的就是这个缺口。
#
# 权重:只按字数给 —— 三字 60000、四字 20000、五字 6000。字数越多,同一串简拼下的对手越少,给得越低越不容易挤到别人;
# 这三个数是在上面第二部分那 45 条上试出来的「够用的最低档」(简拼命中 —— 三字:首选 55%、前八 100%;四字:首选 82%、前三 100%;
# 五字:首选 100%。三字的对手最多:wzm 有「我怎么」、wws 有「往往是」,给到 6 万也只排第二,不再往上加;
# 试过的几档见 scripts/rime-abbr-eval.sh 末尾「第二轮」)。
# 读音:pinyin-pro(后端依赖)注的,再逐条让引擎按这个读音反拼一遍核对(10-07 原稿 202 条里有 36 条拼不出原词,逐条看过:
# 都是引擎把它拼成了同音的另一串字 —— 正是要补这个词的原因 —— 不是读音错)。
#
# 加词:先确认上游没有这个词(有的话去 phrase-weights.txt 抬权重);按字数给数;带上拼音;量一遍 scripts/rime-abbr-eval.sh
# 和 scripts/rime-typo-eval.sh 再提交。**每加一个整词,它的全拼就不再逐字造句、而是先出这个词** —— 加之前先看引擎现在出什么。
#
# 下面这一行「署名」会被构建脚本抄进下发的词库产物的头注释(build-pinyin-dict.mjs 的 parseCreditLines);不要删。
