# Ninan 九宫格补全「索引外词表」：聊天常用词（2026-11-13 同码／简拼调序，3384 词）
# 用途：scripts/gen-t9-completions.mjs 把这些词直接收进九宫格补全索引（不受「按词频取前 1.6 万」限制），
#       随包表与独立 OTA 表都用；只影响九宫格未打完时的补全召回与排序，不进主拼音词库、不改全拼。
# 为什么（2026-11-13 九宫格自查）：少打最后一键找不到目标，约 65% 是补全索引里没有这个词（主词库里有）；
#       按主词库权重整批加 3 万词的原型只补上三分之一、完整码还变差，所以改成这份按聊天口径挑过的词表。
#
# 写法（与 phrase-weights.txt 同序）：词<Tab>权重<Tab>拼音<Tab>范围<Tab>来源<Tab>类别
#   权重：编辑值，不是语料频次，刻度同随包基础词库（基础表词频中位约 270、前 10% 约 1,800、前 1% 约 1.7 万）；
#   拼音：小写、音节间一个空格，与本批配套审核主词库里该词的读音一致（版本见交接及独立表绑定注释）；
#   范围：all = 随包表与 OTA 表都收；ota = 只进独立 OTA 表（来源许可不能随包时用；本版没有）；
#   来源：s2 = agent 按类别自拟的聊天常用词（常识，无外部数据）；nw-key / nw-succ / nw-join =
#         backend/dict/next-word-everyday.txt（Ninan 原创公共联想，Apache-2.0）的前文 / 后继 / 前文+后继拼成的 2–4 字短语。
#   权重规则（按来源分三档，2026-11-13 用 agent 自写的调参用例比过 500～16000 几档后定的）：s2 → 4000（1346 词），
#         联想前文或后继 → 1000（1153 词），只来自前文+后继拼接 → 500（547 词）。档位再高，当前客户端里单音节输入的单字首选
#         会多被抢走几个（要等合并层的单字保护）；再低，词进不了补全桶。
#
# 许可：词形是常用汉语词，来源都是 Ninan 自己写的（上面两类），可以随包（Apache-2.0）。主词库（GPL-3.0）只用来核对
#       「这个词在词库里、读音一致」，权重不取自主词库；不收对标输入法词表派生的短语（common-phrases.txt、
#       chat-phrases-preview.txt 这类，要收得标 ota 并在这里写明来源）。不收任何用户输入或个人数据。
# 挑选规则（机械）：2–6 个汉字（日常整句片段）；在审核主词库里（权重大于 0）且读音与 pinyin-pro（MIT）注音一致（不一致而词库只有一个读音时取词库的）；
#       多读音对不上的不收；以「的 / 了 / 着 / 吗 / 呢 / 吧 / 啊 / 嘛」作助词开头的不收；带「她」的不收（同 everyday-phrases.txt 的规矩）。
# 人工审核（2026-11-13，只删不加）：删去 129 条 —— 联想前文里的半截状态（一起出、下午有、把文件…）、
#       半截后继（你一下、到你、重一点…）、不自然的（热的、坨了…）、非聊天用语（信函、方案实施…）；清单见
#       build/t9-chat-words.nosync/2026-11-13/review-drops.txt（随交接存证据）。对标词表派生的 2,580 条这一版整批不收。
