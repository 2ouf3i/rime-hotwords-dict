# Ninan 短语权重表 —— 每次构建拼音词库时套在上游词条上(backend/scripts/build-pinyin-dict.mjs 的 applyPhraseWeights)
#
# 写法:一行一条,用 Tab 分隔。
#   我今天<Tab>200000                 ← 上游已经有这个词:把它的权重换成这个数
#   某某词<Tab>60000<Tab>mou mou ci   ← 上游没有:带了拼音的加进主表(小写,音节之间一个空格);不带拼音的不加,构建日志会点名
# 同一个词只许写一次(写了两次构建直接失败)。带了拼音、而上游这个词的读音与它不一样的,这一行不生效,构建日志会点名。
#
# 为什么要有这张表(2026-10-07):用户反馈简拼 wjt 的首选是「为家庭」,不是「我今天」。查下来不是词库里没有这个词,
# 是权重不对:上游 rime-ice 的权重标的是「来源层级」不是词频 —— base 层有人工调频,ext 层 34 万条、腾讯层 98 万条恒为 100
# (占位),合起来约七成词条;而只要有一个整词盖住全部输入,引擎就不造句、不问语言模型,候选只按词条权重排。
# 「我今天」在 ext 层(100),「为家庭」在 base 层(13300)。同样的还有「我们的」(ext,100;而「他们的」在 base 是 50 万)。
# base 层自己对口语短语也偏低(它的语料偏书面):「他今天」965、「明天见」4525、「不用谢」5056。
#
# 这一份是**手写的起步表**:最日常的口语短语(人称 + 时间、人称 + 常用谓词、「的」字短语、问句、应答寒暄、时间短语)。
# - **是按常识写的,不来自任何别家产品的数据,也不来自任何用户的输入内容。**
# - 只收上游词库里已经有的词(这张表管的是「已有的词排第几」;上游没有的日常短语放 everyday-phrases.txt,
#   地名放 place-names.txt —— 那一份是生成的;网络热词走 ninan-hotwords.txt)。
# - 只抬不压:表里的数都比上游现在的权重高。上游哪天把某个词调得比表里还高,构建日志会提醒「调低了」,把那一行删掉。
# - 权重分四档,刻度是上游 base 层的刻度(三字词条的中位数约 500,前 10% 在 1.2 万以上):
#     500000  只给在 base 里有「孪生词」排在 50 万的那几条:我们的、你们的(base 里的「他们的」是 50 万,它们却在 ext 层)。
#     200000  最常用的那一批。base 里的同类:我觉得 50 万、我现在 35 万、知道了 21 万、你知道 18 万、没问题 10 万。
#      60000  一般常用。base 里的同类:今天晚上 5 万、可以的 4.8 万、我要去 2.9 万、真的吗 3.1 万。
#      20000  其余。base 里的同类:我明天 2 万(上游原值)、不客气 2.9 万、等一下 2.9 万。
#   给多少没有精确的依据,是拿 base 里同类短语的量级比出来的;改之前后都用 scripts/rime-abbr-eval.sh 量
#   (调参集上各来源层的 首选 / 前三 / 前八,**base 层不许掉**),再跑 scripts/rime-typo-eval.sh 看护栏
#   (比两份权重不同的词库时带上 NINAN_PROBE_GUARD_DICT,见那份脚本头部)。
# - 加词:想到哪条日常短语的简拼排不上来,先确认上游有这个词(构建日志会点名没有的),按上面的档给数,量一遍再提交。
#   一类一类地加(同一类的一起加),不要只补用户举的那一个例子。
# - 抬不到第一的:声母是 zh / ch / sh 的字,简拼只打一个字母时引擎也会把两个字母并成一个声母去解 ——
#   dsh 既是「到时候」(d-s-h)也是「但是」(d-sh),两个字的常用词权重高得多,这张表不去和它们比。
#
# 这张表只管得了几百条。占位层剩下的长尾(一百多万条)要靠一个口语词频的来源去估:构建脚本的 --phrase-weights 可以给多次,
# 这一份放最前面、优先(现在后面跟着 everyday-phrases.txt 与 place-names.txt)。拿本机的拼音语言模型去估的那条路量过、没有采用,
# 过程与数字在 scripts/gen-phrase-weights-lm.sh 末尾;拿公开例句(Tatoeba)对照着补过一批 345 条的权重,量下来收益很小、还挤掉了两条原本对的首选,没有收进来 ——
# 那批例句是教科书语体,聊天里的短语覆盖得很少,也没有拿它去批量估权重。
#
# ⚠️ 这张表会并进 GPL-3.0 词库产物公开下发:只许放公开的日常用语,绝不许放任何只来自单个用户的内容。
# ⚠️ 改了这张表,要等下一次词库发布(scripts/sync-pinyin-dict-local.sh)才到用户手上;发布前先本机构建、本机量。
