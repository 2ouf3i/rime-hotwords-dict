# Ninan 地名读音表 —— backend/scripts/gen-place-names.mjs 给「词库里还没有的地名」定读音时用(行政区划数据不带读音)。
# 这份表本身不进词库构建,也不进同步镜像;它是生成 place-names.txt 的输入之一。
#
# 写法:一行两列,Tab 分隔。
#   长<Tab>chang          ← 一个字:这个多音字在地名里默认读什么
#   长子<Tab>zhang zi     ← 两个字以上:整词的读音(优先于逐字拼;也用来记默认读音的例外)
#   某某<Tab>-            ← 两个字以上:这个名字不收(读音拿不准)
# 读音用上游词库的写法:小写、不带声调、音节之间一个空格,ü 写成 v(绿 lv、略 lve)。
#
# 出处:都是字典 / 地名志上的规范读音,按常识逐条写的、写的时候逐条想过;不来自任何别家产品。
# 没把握的字不写 —— 生成脚本遇到「有多音字、这里又没有交代」的名字会整个不收(宁可缺,不给错的读音)。
# 生成脚本的 --report 会列出:没收的名字(skipped.tsv)、逐字拼出来与上游读音不一样的(chars-vs-upstream.tsv)、
# 与 pinyin-pro 不一样的(reading-diffs.tsv)。往这里加字 / 加词之前先看那三份。
